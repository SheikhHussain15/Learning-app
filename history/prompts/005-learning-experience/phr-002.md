## Prompt

## Phase 5 Plan — Learning Experience

1. Develop the **Learning Workspace** as the central study environment, integrating structured document navigation and dynamically displaying AI-generated content with clear **Not Requested**, **Processing**, **Failed**, and **Completed** states for every optional learning resource.
2. Build the **Learning Dashboard** to present personalized learning insights, including recent activity, study statistics, progress, learning streaks, recommendations, saved notes, and other metrics sourced directly from the Progress Agent.
3. Implement the complete **Quiz Experience**, including quiz selection, question navigation, answer submission, scoring, review mode, and automatic recording of QuizAttempt events that update the Progress Agent.
4. Develop the **Flashcard Review** experience with interactive card navigation, flip animations, basic spaced repetition support, review tracking, and integration with the user's learning progress.
5. Build the **Diagram Viewer** to render structured outputs generated by the Diagram Agent into interactive flowcharts, mind maps, timelines, and concept diagrams with zoom, pan, and responsive viewing capabilities.
6. Implement the **AI Tutor** interface using LlamaIndex and ChromaDB retrieval, enabling contextual conversations grounded exclusively in the user's uploaded documents while providing accurate source references for every response.
7. Integrate all learning interactions with the **Progress** and **Recommendation** systems, ensuring study events, quiz performance, flashcard reviews, reading progress, and tutor activity continuously update personalized recommendations.
8. Apply the complete **design system** across the application, including typography, spacing, responsive layouts, dark/light themes, accessibility standards, loading skeletons, processing indicators, and meaningful empty and error states.
9. Validate the complete learning experience by verifying that users can study a processed document end-to-end, dashboard metrics accurately reflect Progress Agent data, AI Tutor responses remain grounded, diagrams render correctly, and every screen gracefully handles loading, empty, processing, and error states.
